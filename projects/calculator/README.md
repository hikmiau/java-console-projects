# Calculator

A simple console-based calculator that supports basic arithmetic operations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Input validation for numbers
- Division by zero handling
- Exit with 'quit' command

## Running

```sh
cd projects/calculator/src
javac Calculator.java
java Calculator
```

## Example Usage

```
Simple Calculator
Choose operation: + - * / (or 'quit' to exit)
Operation: +
Enter number: 10
Enter number: 5
Result: 15.0
Operation: quit
Goodbye!
```
