# Java Console Projects

A collection of small Java console projects focused on programming fundamentals, clean code, and practical problem solving.

## Goals

- Practice Java syntax
- Practice object-oriented programming
- Build small console applications
- Keep code readable and simple
- Avoid unnecessary nesting
- Use clear names and small functions

## Projects

| Project | Concepts |
| --- | --- |
| Grade System | input, lists, averages, conditionals |
| Calculator | input validation, loops, switch expressions, error handling |
| Todo List Manager | OOP design, stream processing, separation of concerns, user interaction |

## Requirements

- Java 21 or newer

## Running a project

Enter the project folder:

```sh
cd projects/grade-system/src
javac GradeSystem.java
java GradeSystem
```

Or for Calculator:

```sh
cd projects/calculator/src
javac Calculator.java
java Calculator
```

Or for Todo List Manager:

```sh
cd projects/todo-list-manager/src
javac *.java
java TodoListApplication
```
